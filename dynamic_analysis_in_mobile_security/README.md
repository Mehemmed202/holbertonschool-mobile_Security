# Android Dynamic Application Security AnalysisThis repository contains the dynamic security assessment of a protected Android application (APK). The project focuses on runtime instrumentation, intercepting network communications, bypassing client-side security controls, and identifying runtime vulnerabilities using industry-standard tools.Project OverviewWhile static analysis inspects source code, dynamic analysis reveals an application's behavior during runtime. This project demonstrates how an attacker or security researcher can bypass modern client-side protections—such as code obfuscation, root detection, and SSL pinning—by directly manipulating the application's runtime state.ObjectivesBy completing this assessment, the project covers:Dynamic vs. Static Analysis: Differentiating between code inspection and runtime manipulation.Instrumentation & Hooking: Injecting custom scripts into running processes using Frida.Security Control Bypasses: Circumventing Root Detection and breaking SSL Pinning to inspect encrypted traffic.Network Traffic Interception: Capturing and analyzing HTTP/HTTPS requests to identify insecure data transmission.Runtime Exploitation: Utilizing Objection to automate memory inspection, class enumeration, and key extraction.Vulnerability Reporting: Documenting security findings, risk levels, and remediation steps.Tools & TechnologiesCategoryTools UsedDynamic Analysis & HookingFrida, Objection, ADB, GDBNetwork InterceptionBurp Suite, mitmproxy, WiresharkReverse Engineering & DisassemblyJADX, APKTool, Ghidra, IDA ProEnvironment & ScriptingAndroid Emulator (AVD) / Rooted Device, Python, Bash/
